**Phase 5 slice 62 landed 2026-04-20** (build + 107 JVM tests green across five consecutive runs; no schema change):

- **Init-time cleanup is now awaited by all in-progress-row readers (Bug 4 of the timer + edit/resume triage).** Before: the `init` block fired `viewModelScope.launch(Dispatchers.IO) { cleanupAbandonedSessions() }` fire-and-forget, and `startWorkoutFromTemplate` / `resumeInProgressWorkout` / `checkForInProgressWorkout` / `loadWorkoutForEdit` read the same `isInProgress` column their own IO launches without any synchronization against the init cleanup.
